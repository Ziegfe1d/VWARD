# VWARD WAN Guard

Исходники в `scripts/` получены из проверенного snapshot рабочего роутера.

`wan-guardian.sh` выполняет ступенчатую диагностику и восстановление текущего
`ISP`/`eth3` WAN-пути. `wan-recovery-actuator.sh` выполняет узкое действие обновления
DHCP-клиента.

Идентификаторы устройства необходимо обнаружить или настроить до переноса компонента
на другой роутер.
