# VWARD WAN Guard

Исходники в `scripts/` получены из проверенного snapshot рабочего роутера.

`vward-wan-guard.sh` выполняет ступенчатую диагностику и восстановление текущего
логический и физический WAN-пути из Device Profile. `vward-wan-recovery.sh` выполняет узкое действие обновления
DHCP-клиента.

Идентификаторы устройства необходимо обнаружить или настроить до переноса компонента
на другой роутер.
