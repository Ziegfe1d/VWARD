# План следующего выпуска (после `0.2.0-rc.2.fix.1`)

Улучшения и новые возможности, которые владелец 2026-10-03 перенёс из фикса
[`FIX_PLAN_RC2_FIX1.md`](FIX_PLAN_RC2_FIX1.md): в фикс входит только устранение ошибок,
стабильность и скорость.

## Панель VWARD

1. Плитки на «Обзоре» одного размера; в настройках плиток переключатель «Показывать дополнительные
   подписи», подписи занимают одно и то же число строк (1 или 2), чтобы плитки и строки списка совпадали.
2. Проверка обновлений: «Проверить сейчас» и автоматическая проверка по расписанию, как у установки
   (выбор времени, автоустановка отдельно).
3. Дизайн, четыре пункта: кнопки с длинным текстом во всю ширину; длинное значение под названием
   строки; серые заготовки вместо прочерков при загрузке; «обновлено N мин назад» у блока вместо
   жёлтой плашки.
4. В «Система → Стабильность» показать события `TCPDUMP_RESTART` (интерфейс и число быстрых падений).

## Туннели

1. Подписка VLESS как один туннель-группа (предложение владельца 2026-10-04). Сейчас из подписки
   создаётся туннель на один выбранный сервер. Нужно: добавить подписку целиком («Все серверы»), на
   странице туннеля - список серверов, сгруппированный по странам, у каждой страны и сервера свой
   переключатель «использовать»; режим «подбирать автоматически». Программа сама замеряет
   доступность и пинг серверов, отключает недоступный (ответа нет несколько проверок подряд) и
   включает обратно, когда он снова отвечает; данные подписки обновляются по расписанию (новые
   серверы появляются, пропавшие убираются, выбор владельца сохраняется). Основа: движок
   `vward-vless-engine.sh` (один Xray на туннель) и `vward-tunnel-quality.sh` (замеры); вопросы:
   один процесс Xray на группу с балансировщиком/`observatory` или переключение сервера в
   конфигурации, лимит памяти на MIPS (30-60 МБ на процесс), замер без трафика через сервер.

## Решения владельца

- Резервный DNS: если AdGuard Home не отвечает дольше 2 минут, временно добавлять в Keenetic
  name-server провайдера и убирать, когда AdGuard Home поднимется. Плюс: интернет есть всегда.
  Минус: пока резерв включён, реклама не фильтруется и Smart DNS (Aeternia) не работает.
  Включение по умолчанию - вопрос владельцу.
- Токен Aeternia: запускать `https-dns-proxy` так, чтобы токен читался из файла, а не из аргументов,
  если программа это позволяет.
