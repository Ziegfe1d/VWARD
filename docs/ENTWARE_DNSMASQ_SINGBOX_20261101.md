# dnsmasq и sing-box в общем выпуске VWARD — аудит совместимости и состояние (01.11.2026)

**Решение владельца от 01.11.2026:** интеграция dnsmasq и sing-box входит в текущий общий
приёмочный выпуск (sing-box больше не отдельный fix.40). Оба компонента **по умолчанию выключены**:
«установлен, выключен» сохраняется после установки, обновления и перезагрузки. Xray остаётся основным
движком VLESS, AmneziaWG сохраняется, AdGuard Home — DNS по умолчанию. На действующем роутере ничего
не устанавливалось и не включалось.

## 1. Что проверено, а что — нет

| Вопрос | Источник | Результат |
|---|---|---|
| Модель/прошивка | self-test 31.10 | Keenetic Viva KN-1913, KeeneticOS 5.01.C.8.0-2, `arch: mips` |
| Архитектура Entware | self-test | **не доказано**: `mips` без порядка байтов. Для MT7621 ожидается `mipselsf-k3.4`; проверка на устройстве — `opkg print-architecture` (read-only) |
| Память | self-test | 254 MB, доступно 81 MB, load 5,79 в пике |
| Занятые DNS-порты | self-test | `:53` — `ndnproxy` (Keenetic); AGH — `:65053`; 8 процессов `https_dns_proxy` (Smart DNS DoH); `avahi-daemon` (mDNS) |
| Процессы VWARD-окружения | self-test | AdGuardHome, xray, lighttpd, vward-sentinel, crond; AmneziaWG-процесса нет (туннель в ядре/неактивен — не проверено) |
| Индекс Entware (`dnsmasq-full`, `sing-box-go`: версии, зависимости, размер, SHA256, postinst, сборочные теги) | `bin.entware.net` | **не проверено**: хост закрыт сетевой политикой среды разработки. Нельзя считать наличие `.ipk` доказательством работоспособности |

Поэтому код определяет возможности **на устройстве во время проверки** (вывод `dnsmasq --version` —
«Compile time options», `sing-box version` — «Tags»), а неизвестное считает неподдерживаемым.

## 2. Ожидаемые возможности (проверяются кодом, не принимаются на веру)

| Функция | Движок | Что требуется доказать | Если не доказано |
|---|---|---|---|
| `server=/домен/адрес`, `address=/домен/0.0.0.0` | dnsmasq | базовые функции dnsmasq | — |
| `ipset=` / `nftset=` | dnsmasq | опции `ipset`/`nftset` в compile options | не используются |
| DNSSEC, DoH | dnsmasq | `dnssec`; DoH в dnsmasq нет | DoH остаётся за https_dns_proxy/AGH |
| VLESS + REALITY | sing-box | `with_utls` в тегах (REALITY) | туннель остаётся на Xray |
| XHTTP | sing-box | в известных сборках sing-box транспорта XHTTP нет | **всегда Xray** |
| WireGuard | sing-box | встроенный endpoint/`with_wireguard` | остаётся на штатном WireGuard Keenetic |
| AmneziaWG | sing-box | не эквивалент WireGuard; поддержка не заявлена | **всегда AmneziaWG** |
| QUIC/Hysteria2/TUIC | sing-box | `with_quic` | недоступно |
| Cloudflare WARP | sing-box | WireGuard-профиль WARP + проверка | недоступно |
| Несколько URL подписок | VWARD | разбор подписки VWARD, не движка | — |

## 4. Аппаратные проверки (только по разрешению владельца)

1. `opkg print-architecture`, `opkg info dnsmasq-full sing-box-go` — read-only.
2. Загрузка пакетов в кэш без установки, сверка SHA256 с индексом, разбор `postinst`.
3. Установка «выключенным» на отдельном разрешении; замер памяти и CPU на Viva.
4. Переключения DNS и VPN-движка — только после адресного аудита и отдельного разрешения.
