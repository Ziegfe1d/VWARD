# Агенты VWARD: разбор и предложение

Пункт плана: разобрать все текущие стражи и разбить их по зонам ответственности, по одному
агенту на зону, без пересечений. Сколько агентов будет, решает владелец по итогам разбора.
Код ещё не менялся.

## Что есть сейчас (10 программ)

| Программа | Что делает | Как часто |
|---|---|---|
| Агент интернета (wan-guard, wan-recovery) | Нет интернета: обновляет адрес, перезапускает подключение к провайдеру | раз в минуту |
| Агент VPN (tunnel-guard) | VPN не отвечает: списки идут напрямую или в запасной туннель, потом назад | раз в минуту |
| Проверка туннелей (tunnel-health) | Измеряет туннели, держит запущенными модули AmneziaWG и VLESS | раз в минуту |
| Агент DNS (dns-guard) | AdGuard Home в цепочке DNS Keenetic, выводит и возвращает его, перехват DNS | раз в минуту |
| Сверка маршрутов (route-reconciler) | Возвращает напрямую то, что снова открывается без VPN | раз в 5 минут |
| Агент реального времени (sentinel) | Следит за интерфейсами, памятью, процессами и DNS; при событии зовёт нужного агента | постоянно |
| Агент расписания (cron-supervisor) | Держит работающими cron и Панель, запускает AdGuard Home после загрузки, утечки памяти без агента реального времени | раз в 10 с |
| Обслуживание (housekeeping) | Журналы, копии настроек, брошенные замки, ежедневные проверки обновлений других программ | раз в час |
| Обновления VWARD (updater-watch) | Проверка и установка обновлений VWARD | раз в 15 минут |
| Агент Wi-Fi (wifi-client-guard) | Диапазоны Wi-Fi для устройств | раз в 5 минут |

## Пересечения, найденные при разборе

1. **Запуск AdGuard Home** делают двое: агент расписания (первые 30 минут после загрузки) и
   агент реального времени (событие «dns-fail»). Ворота у них общие, двойного запуска нет, но
   ответственных двое.
2. **Молчащий AdGuard Home в цепочке DNS** выводят двое: агент DNS (раз в минуту, 3 проверки) и
   агент реального времени (событие «chain-fail», за 15 секунд).
3. **Модули туннелей** перезапускают двое: проверка туннелей (держит запущенными) и агент VPN
   (перезапускает туннель модуля перед тем, как пустить списки напрямую).
4. **Утечки памяти** ловят двое: агент реального времени и, когда его нет, агент расписания.
   Это задумано как запасной путь.
5. **Перезапуск Панели** делают двое: агент расписания (упала) и обслуживание (пришли новые
   настройки веб-сервера).

## Предложение: 4 агента

| Агент | Зона | Кто в него входит |
|---|---|---|
| **Агент сети** | Интернет, VPN, DNS, маршрутизация | агент интернета, агент VPN, проверка туннелей, агент DNS, сверка маршрутов |
| **Агент компонентов** | Каждая программа VWARD и AdGuard Home работает | агент расписания, запуск AdGuard Home, модули туннелей, утечки памяти, Панель |
| **Агент обновлений** | VWARD, AdGuard Home, Entware, прошивка, списки | обновления VWARD, ежедневные проверки других программ |
| **Агент обслуживания** | Журналы, копии настроек, место на флешке | обслуживание |

Агент реального времени перестаёт быть отдельным агентом: это общие «глаза», которые сообщают о
событии агенту нужной зоны (интерфейс провайдера → агент сети, пропал процесс → агент
компонентов). Агент Wi-Fi остаётся частью компонента «Wi-Fi».

После этого каждое действие делает ровно один агент:
- AdGuard Home запускает только агент компонентов;
- из цепочки DNS выводит только агент сети;
- модули туннелей перезапускает только агент компонентов, по просьбе агента сети;
- Панель перезапускает только агент компонентов.
