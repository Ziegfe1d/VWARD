## Структура кода

- 12 копий чтения запроса и 11 копий разбора формы в API заменены общими функциями;
  4 копии декодирования (конфиг туннеля, имя устройства, пароли, адреса) - одной с режимами.
- Одно правило секретов для просмотра файлов и резервных копий.
- Настройки читаются за один проход по файлу вместо процесса на каждый ключ
  (на 47 процессов меньше на странице настроек); ответы совпадают байт в байт.
- Все `rm -rf` с переменной защищены `${VAR:?}` (30 скриптов).
- Большинство замечаний ShellCheck ложные (переменные из подключаемых файлов, awk/jq
  в одинарных кавычках); настоящие ошибки исправлены выше.

## Нужно ваше решение

1. **Движок обновлений не обновляет сам себя.** Список файлов, которые он может установить,
   зашит в него и меняется только ручной переустановкой. Любой новый файл в VWARD требует
   такой переустановки. Предлагаю сделать подписанное самообновление движка - отдельная
   большая задача.
2. **Вход в консоль выключен по умолчанию.** После исправления S1 чужие сайты не доберутся,
   но любое устройство в домашней сети может менять настройки. Рекомендую включить вход
   или «только зарегистрированные устройства».
