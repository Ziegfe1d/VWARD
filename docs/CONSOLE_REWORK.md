# VWARD Console: список доработок

Рабочий список изменений интерфейса Console по итогам просмотра демо-страницы.
Отмечаем выполненное прямо здесь.

## Правило для всех этапов

Изменение интерфейса правит существующий код, а не дописывает поверх. Новое CSS-правило
заменяет старое; одно и то же свойство одного элемента задаётся в одном месте.

## Этап 1. Основа: чистый CSS

- [ ] Свести `vward-console.css` к одному набору правил без многослойных переопределений
      (сейчас, например, у кнопок нижней панели около 10 перекрывающих правил).
- [ ] Единые токены: цвета светлой и тёмной темы, шрифты, размеры, отступы, радиусы, тени.
- [ ] Проверить выравнивание текста, шрифты, анимации, переходы, заливки, линии; убрать
      наслоения текста.
- [ ] Регрессионная проверка: одно свойство одного селектора не переопределяется повторно.

## Этап 2. Иконки

- [ ] Перерисовать все иконки в едином формате и стиле: одна сетка, толщина линии,
      скругления (обновление, тема, уведомления, поиск, навигация, действия).

## Этап 3. Шапка и навигация

- [ ] Убрать синий блок статуса на главном экране.
- [ ] Колокольчик уведомлений справа в шапке: спокойный, когда всё в порядке; счётчик
      при неполадках; по нажатию - список проблем со ссылкой на нужный раздел.
- [ ] Общий поиск значком рядом с колокольчиком: ищет по всей Console (разделы, настройки,
      компоненты) и переходит к найденному; убрать поля поиска со страниц.
- [ ] Компактные кнопки шапки на узком экране.
- [ ] Нижняя панель на телефоне: непрозрачный фон, контент не уходит под панель, подписи
      без обрезки (короче или меньше пунктов), подложка активного пункта не выходит за край.
- [ ] «Назад к обзору» не уезжает под верх экрана.

## Этап 4. Содержимое страниц

- [ ] Карточки обзора: метки статуса не выходят за край, нет залипающей рамки после
      касания, иконка выровнена по верху с текстом, одинаковое описание на телефоне и
      компьютере, компактная высота.
- [ ] «Настроить карточки» - компактная кнопка или пункт меню, без отдельной строки.
- [ ] Характеристики на всех страницах - компактный список «название - значение» с тонкими
      разделителями вместо сетки плиток; цветная метка только там, где есть состояние.
- [ ] Без вложенности «карточка в карточке в карточке».
- [ ] Понятные русские метки вместо «READ ONLY», «ТОЛЬКО VWARD» и подобных.

## Этап 5. Вход в Console

- [ ] Логин и пароль те же, что у веб-интерфейса Keenetic; проверка через штатную
      авторизацию роутера (`/auth`), пароль в VWARD не хранится.
- [ ] Сессия с ограниченным сроком; без входа закрыты страница и API.
- [ ] Включается настройкой; на время разработки по умолчанию выключено.
- [ ] Формат ответа `/auth` проверить на реальном роутере.

## Приёмка каждого этапа

- ширина экрана от 320 до 1440 px, светлая и тёмная тема;
- нет наложений, обрезанного текста и горизонтальной прокрутки;
- браузерная проверка без ошибок JavaScript;
- тесты репозитория проходят; демо-страница обновлена для просмотра.
