# Политика веток и версий VWARD

## Beta: `main`

`main` содержит установленную beta-линию. Для `0.1.7-beta` разрешены только
исправления подтверждённых ошибок, безопасности, совместимости и документации.

Последующие версии именуются `0.1.7-beta.1`, `0.1.7-beta.2` и далее. Новые функции,
рефакторинг и изменение архитектуры в Beta не добавляются.

Каждый beta-fix проходит полный CI, подписывается production Ed25519-ключом и только
после проверки публикуется в feed. Исправление затем переносится вперёд в `dev`.

## Development: `dev`

`dev` содержит активную линию `0.2.0-dev.x`. Здесь выполняются полная доработка,
Zero-Hardcode, discovery устройства, унификация компонентов, интерфейса, API,
конфигурации и внутренних имён.

Изменения из `dev` не переносятся обратно в Beta. Выпуск на рабочий роутер возможен
только отдельным подписанным пакетом после прохождения acceptance и явного решения о
повышении зрелости версии.

## Направление синхронизации

`main` (Beta fixes) -> `dev` (активная разработка).

Обратное массовое слияние запрещено. Название продукта во всех линиях остаётся
`VWARD`.
