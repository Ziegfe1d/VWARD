# Политика веток и версий VWARD

## Production: `main`

`main` содержит только одобренную production-линию. До Final допустимы лишь
подтверждённые исправления production-совместимости и безопасности с отдельным
решением владельца.

Новые функции, рефакторинг и архитектурные изменения в `main` не добавляются.
Каждое обновление проходит полный CI, подписывается production Ed25519-ключом и
публикуется только после соответствующего release gate.

## Development: `dev`

`dev` содержит активную линию `0.2.0-dev.x`: доработку, discovery устройства,
унификацию компонентов, интерфейса, API, конфигурации и внутренних имён. Package и
feed из `dev` не устанавливаются на рабочий роутер без отдельного signed acceptance.

Изменения из `dev` не переносятся в `main` до Final gate. Выпуск на рабочий роутер
возможен только отдельным подписанным пакетом после acceptance и явного решения
владельца.

## Направление синхронизации

`main` (подтверждённые production fixes) → `dev` (активная разработка).

Обратное массовое слияние запрещено. Название продукта во всех линиях остаётся
`VWARD`.
