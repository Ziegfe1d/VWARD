## 3. Включение сервиса отказывает: `service_reference_only` (новое, скриншот владельца 22:17)

Что видно: в уведомлениях Панели «Не выполнено: список создан или изменён пользователем; автоматическое изменение
запрещено» в 19:56 и 22:17; «ChatGPT идёт через VPN» в 19:46 - прошло. Владелец пробовал включить YouTube.

Что проверено в коде (`vward-console-config.sh`, строки 2822-2860, `vward-console.js`, строка 282):
- Текст - это ошибка `service_reference_only`.
- Она возникает при включении или смене сервиса, когда для него уже есть строка в `services/enabled.tsv` с группой, которой
  VWARD не владеет (нет файла `services/owned/<группа>`), и список не совпал с тем, что сервис задаёт по каталогу
  (`service_reference_matches`). VWARD намеренно не меняет чужой список.

Не проверено (нужен роутер): к какой группе привязан сервис в `enabled.tsv`, есть ли `owned/domain-list25`, и что
записал журнал в 22:16:51 (владелец пересказывает запись `service_reference_only` с пустым ID сервиса - в присланных
журналах за 22:00 её нет, журналы кончаются 17:00). Связь с `domain-list25` поэтому **гипотеза**.

Оценка совета, который владелец получил из другого чата (текст вставлен в сессию):
- «`domain-list25` - вероятный блокировщик YouTube» - не подтверждается: по замеру 17:13 список уже направлен в OpkgTun0
  и YouTube идёт через туннель. Он блокирует только включение карточки «Сервисы -> YouTube» (VWARD не хочет вести
  чужой список), а не путь трафика.
- «Выбрать в списке рабочий VLESS (OpkgTun4)» - неверно: OpkgTun4 удалён 12.11, рабочий туннель - OpkgTun0.
- «Открыть список и выбрать маршрут VPN, Панель предложит «Взять»» - так задумано (`list-adopt`, fix.38.1), но
  YouTube уже идёт через туннель, этот шаг ничего не ускорит.
- Рекомендация: `domain-list25` не менять. Менять нечего, пока не выяснена причина молчаний туннеля (раздел 2).

прогон в эмуляторе дошёл до конца; на роутере не выполнялась.

```sh
clear
(
P=vward-lists
ls -1t /tmp/$P-*.txt 2>/dev/null | tail -n +5 | while read -r F; do rm -f "$F"; done
OUT="/tmp/$P-$(date +%Y%m%d-%H%M%S).txt"
ln -sfn "$OUT" /tmp/last_result.txt
ln -sfn "$OUT" /tmp/last_$P.txt

send_out() {
  ESC=$(printf '\033')
  sed "s/${ESC}\[[0-9;?]*[a-zA-Z]//g" "$OUT" | tail -c "$MAXB" | base64 | tr -d '\r\n' | { read -r B; printf '\033]52;c;%s\a' "$B"; }
}
on_abort() { trap '' INT TERM HUP; rm -rf "$W"; send_out; echo "[ ABORTED ]: PARTIAL RESULT SAVED TO /tmp/last_result.txt"; exit 130; }
trap on_abort INT TERM HUP
mkdir -p "$W"
{
echo "=== VWARD LISTS CHATGPT AND YOUTUBE (read-only) $(date '+%Y-%m-%d %H:%M:%S') ==="
KC=/tmp/vward-keenetic/running-config

echo "=== END ==="

echo "SUMMARY: ok=$(grep -c '\[ OK \]' "$OUT") warn=$(grep -c '\[ WARNING \]' "$OUT")" | tee -a "$OUT"

echo "RESULT SENT (OSC52)"
```
