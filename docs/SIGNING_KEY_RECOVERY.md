# Ключ подписи обновлений VWARD

## Каноническая идентификация

- Алгоритм: Ed25519.
- Key ID: `vward-prod-2026-01`.
- SHA-256 DER-формы публичного ключа:
  `21a2eed6544e759666cc664acbaec1b786e392f5bd1e258bec353c24da8da0d0`.
- Канонический публичный ключ: `config/updater/update-public.pem`.
- GitHub Actions Secret: `VWARD_PROD_ED25519_PRIVATE_KEY_PEM`.

## Правила хранения

Закрытый ключ не сохраняется в Git, документах, Library, на роутере или в сообщениях.
Рабочая копия должна храниться в GitHub Actions Secret. Резервная копия допускается
только в зашифрованном хранилище владельца.

Перед подписью workflow обязан получить публичный ключ из закрытого ключа и сравнить
его SHA-256 с каноническим публичным ключом. Несовпадение блокирует публикацию.

## Потеря закрытого ключа

Проверка подписи не отключается. Если обе защищённые копии утрачены, создаётся новая
пара Ed25519, новый публичный ключ вручную устанавливается на доверенном роутере через
SSH, после чего выполняется подписанное тестовое обновление и фиксируется новый key ID.
