# Contributing

Проект пока формирует стабильную архитектуру.

Перед изменением:
1. не затрагивать системный nginx Keenetic;
2. не менять AdGuard Home;
3. не добавлять секреты в код;
4. не привязывать решение к одному IP/модели без fallback;
5. любое конфигурационное изменение делать транзакционно: backup → apply → verify → rollback.

Для UI желательно сохранять mobile-first подход и русскоязычный интерфейс.
