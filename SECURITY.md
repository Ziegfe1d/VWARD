# Security

## Никогда не публиковать

- WireGuard `PrivateKey`;
- WireGuard `PresharedKey`;
- API-токены;
- пароли;
- полные router startup-config/self-test без очистки;
- журналы, содержащие персональные DNS-запросы или идентификаторы устройств.

## Принципы проекта

1. Панель слушает только LAN-адрес.
2. Системный nginx Keenetic не изменяется.
3. AdGuard Home не изменяется.
4. Backend не отдаёт криптографические ключи в браузер.
5. Любая запись конфигурации должна иметь backup и rollback.
6. Публичный релиз не должен содержать настройки конкретного домашнего роутера.

## Сообщение об уязвимости

До первого стабильного публичного релиза — через private contact владельца репозитория.
Не публикуйте секреты в GitHub Issues.
